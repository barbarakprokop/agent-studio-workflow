# Security and publication boundaries

This is a **synthetic public example**, not the private Agent Studio implementation.

- No keys, credential IDs, tokens, environment files, internal URLs, database identifiers or real article content are included.
- The example has **no network nodes**, no webhook trigger, no API requests, no AI model credentials and no publishing mechanism.
- Never add a production n8n export or WordPress snippet to this repository without a separate secrets, configuration, privacy and Git-history review.
- If adapting the architecture, protect all API endpoints, rate-limit external inputs, validate payloads and enforce human permissions server-side.
- Do not rely on a language model's text as proof of human approval.

Please report any concern privately via the contact information on [the portfolio](https://barbarakprokop.com/productdesign/), not by posting suspected secrets in a public issue.
